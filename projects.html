Selected work

Technical projects.

A selection of my work in mapping, data analysis and software development.

QGIS

Campus accessibility map

I mapped the step-free route from the college gate to the library. The printed map marks the ramp, stairs and return box so a first-time visitor can find the accessible entrance.

Microsoft Excel

Campus travel survey dashboard

I built an Excel dashboard from a student travel survey. It shows how travel habits vary by distance from college and lets the reader filter responses by year of study.

SQLite

Field equipment loan register

I created a database to track equipment issued for fieldwork. It records the borrower, item and return date, and produces a list of equipment that is still on loan.

Java

Badminton court queue

I built a small console program to manage the waiting list at badminton practice. It assigns the next four players to a doubles court in arrival order and adds returning players to the end of the queue.

HTML, CSS and JavaScript

Field photograph catalogue

I organised photographs from campus surveys in a browser-based catalogue. Each photograph has a location and caption, and visitors can filter the collection to find images from a particular site.
